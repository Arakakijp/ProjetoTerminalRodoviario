# Projeto Terminal Rodoviário

## Desenvolvimento de Aplicativo Android para Comunicação Operacional em Terminal Rodoviário

Projeto acadêmico desenvolvido na disciplina de Programação para Dispositivos Móveis em Android.

## Objetivo

Desenvolver um aplicativo Android simples e funcional para auxiliar na comunicação operacional, registro de ocorrências e organização das atividades realizadas no Terminal Rodoviário de Campo Grande.

## Funcionalidades propostas

- Registro de ocorrências operacionais;
- Solicitação de manutenção;
- Organização de informações operacionais;
- Comunicação entre equipes;
- Registro de atividades da limpeza;
- Centralização de informações importantes.

## Tecnologias utilizadas

- Android Studio;
- Kotlin;
- GitHub;
- Programação Mobile Android.

## Estrutura inicial do projeto

O projeto foi iniciado utilizando a estrutura padrão do Android Studio com linguagem Kotlin, contendo arquivos iniciais da aplicação Android e organização das pastas do sistema.

## Objetivos acadêmicos

- Aplicar conhecimentos de programação mobile;
- Desenvolver habilidades em Android;
- Utilizar ferramentas de versionamento;
- Praticar organização de projetos de software;
- Relacionar teoria e prática em um projeto real.
